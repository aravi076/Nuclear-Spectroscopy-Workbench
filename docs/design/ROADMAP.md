# Roadmap

Dates are targets. A release is made when its criteria are met, not when its date
arrives.

## v0.1.0-alpha — engines and seven desktop pages

Done: data model, Lynx importers, measurement identity and integrity, spectrum viewer,
background subtraction, peak search, peak fitting, energy calibration, resolution
analysis, synthetic generator; engines for decay, efficiency, activity and nuclide
candidates (synthetic and fictitious inputs only).

## v0.9.0-beta — complete workflow (target 22–25 November 2026)

State 2026-11-12: implemented (pages, project file, reports, validation runner,
executable); import of real nuclear data waits for redistribution terms; manual GUI
testing and a clean-machine installation are open.

- Desktop pages: Efficiency Calibration, Activity Calculation, Nuclide Identification.
  Each lists missing inputs instead of computing when information is absent.
- Import of nuclear reference data with provenance (DDEP primary, ENSDF supplementary),
  once the redistribution terms of each source are settled; until then by user-supplied
  files only.
- Consolidated validation runner with repeatability checks; bias, coverage,
  false-detection and detection-probability tables regenerated by one command.
- SQLite project file: measurements, calibrations, fits, results, settings and
  provenance, append-only history.
- Reports (PDF, SVG, CSV) that allow a result to be reconstructed.

## v1.0.0 — stable (target 28–29 November 2026)

- Windows executable (PyInstaller) tested in a clean environment.
- GUI workflows exercised by hand; installation instructions tested.
- Survey of public HPGe and NaI(Tl) datasets for external benchmarking.
- Final regression, documentation and release audit.

## After v1.0 (candidates, in order of scientific value)

1. Low-energy tail in the HPGe peak model.
2. Decision threshold and detection limit for weak peaks.
3. Gain-drift detection and time-dependent energy calibration.
4. Fit positions and widths taken from stored calibration and resolution models.
5. Energy axis in plots for verified calibrations.
6. True-coincidence-summing and self-attenuation corrections.
7. Batch processing, multi-spectrum comparison, quality-control checks.
8. Continuous integration; type checking of the tests.

## Needs input from the laboratory

Source certificates (activity, reference date, uncertainty), source–detector geometry,
detector model, and confirmation of line assignments. Without them the measured spectra
stay in channel units and no experimental efficiency or activity is reported.
